# Candy artwork

Generated with the built-in imagegen tool using the imagegen skill. Ten original transparent PNG sprites are integrated into home, gameplay and the power recipe guide. Originals remain in the Codex generated-images folder; production copies are in `Assets/Resources/CandySprites/`. Unity imports these as 512px sprites. Existing gem type IDs and save data are unchanged.

Normal IDs: 0 red, 1 blue, 2 green, 3 purple, 4 yellow, 5 orange. Powers: horizontal stripe, vertical stripe, wrapped area bomb, rainbow color bomb.

## Exact prompt set

Verification: all 12 EditMode tests passed, Android and Editor C# compilation passed, and all 28 isolated Play Mode checks passed without a runtime error report. Reviewed live UI captures are in `Documentation/Previews/home.png`, `game.png` and `power-guide.png`. These checks do not replace testing a newly signed Android build on a physical device.
